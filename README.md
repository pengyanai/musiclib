# musiclib

把本地音乐收藏搬进 macOS Apple Music：读 iPod 曲库、转码打标、导入、补歌词、洗掉下载站的元数据广告。

## 它解决什么

Music.app 的 `add` 用相对路径时会正常返回但不添加任何东西——循环照常打印「已发送」，曲库却一首没进。所以导入一律用曲库自己的曲目数增量核对。

## 能力边界

| 能力 | 状态 |
|---|---|
| 导入文件到曲库 | ✅ 以曲目数增量为准 |
| 元数据（标题/艺人/专辑/流派/年份/曲序） | ✅ |
| 专辑封面（嵌入源文件） | ✅ |
| 专辑封面（源文件没有时下载） | 🟡 接 sacad；**中文专辑名搜不到** |
| 纯文本歌词 | ✅ 写入 `track.lyrics` |
| **清理下载站/翻录工具的元数据广告** | ✅ |
| **艺人头像** | ❌ 平台限制，见下 |
| **逐字 / 滚动歌词** | ❌ 平台限制，见下 |

后两项不是没做，是**做不到**：

- **艺人头像**：Music.app 只渲染 Apple 云端按 catalog ID 返回的艺人图片。本地文件没有承载它的字段，写什么都不会显示。
- **逐字歌词**：同样需要 catalog ID 匹配的云端 TTML。CD 抓轨的歌没有 ID，LRC / TTML / 同名 `.lrc` 四种写法均不被解析。

调用这两项会直接抛 `Unsupported`，附平台原因——见 `docs/LYRICS.md`。

## 安装

```bash
git clone git@github.com:pengyanai/musiclib.git
cd musiclib
python3 -m pip install -e .        # 或直接把仓库根加入 PYTHONPATH
```

无第三方依赖，只需 Python 3.9+ 与 macOS（`osascript`、`ffmpeg`）。

## 用法

```python
from musiclib import itunesdb, convert, musicapp, lyrics

# 1. 读 iPod 数据库（只读）
tracks = itunesdb.read_all(
    "~/Downloads/iPod_Classic/iPod_Control/iTunes/iTunesDB",
    music_root="~/Downloads/iPod_Classic/iPod_Control/Music",
)

# 2. 转码为带标签与封面的 AAC
conv = convert.Converter(src_root, out_dir="/tmp/music_m4a")
print(convert.summarize(conv.run(tracks)))

# 3. 导入，并用曲目数增量确认
musicapp.add_files(f"/tmp/music_m4a/{t['outname']}" for t in tracks)

# 4. 回读曲库（导入后的唯一可信来源）
library = musicapp.read_library()

# 5. 补纯文本歌词（幂等，跳过已有）
print(lyrics.enrich(library))
```

## 三个容易漏掉的地方

这三条不做的话，症状各不相同，但都不会报错：

1. **`add` 必须给绝对路径**。`POSIX file` 按 Music 自己的工作目录解析，相对路径返回 `-1700`。
2. **必须显式清空 `disc`**。源 AIFF 尾部 ID3 有 `TPOS=1`，ffmpeg 继承后 Music 会把文件改名成 `1-08 xxx.m4a`。`-metadata track=` 覆盖不了它。
3. **封面按专辑取，不按曲目取**。封面只嵌在专辑中某一首上，逐曲查会让同专辑其余曲目没有封面。

## 清理元数据广告（`musiclib/scrub.py`）

下载站、转码器、转载者会在标签里留下指纹，它们会跟着文件进每一个曲库：

```
description  "Packed by Bilibili XCoder v2.0.2"
comment      "Generated by SSSTWITTER.COM"
comment      "converted by convert2mp3.net"
artist       "SoundJay.com Sound Effects"
album        "某歌手（资源分享） - 某会议实录"
title        "[SomeSite.Com] [某演讲] [1745978100] "
id3v2_priv.XMP  "<?xpacket begin=…"（整块 XML）
synopsis     整段开户入金送股票的引流文案
```

**能识别的形态**：方括号站点名、裸域名、URL、`Packed/Generated/Converted by`
签名、`_BV…` 视频号、`[epoch]` 时间戳、下载站话术（资源分享/关注公众号/QQ群）、
引流链接（开户/邀请/Join this channel）、XML 元数据块、整段广告。

**`title` / `artist` / `album` 也照洗**——广告在名字里就得从名字里去掉。
唯一的下限是：洗空时换成 `Untitled` / `Unknown Artist` / `Unknown Album`，
因为没名字的曲目在库里找不回来，比留个广告难修。

**广告占比过高时整段清空**，而不是逐句抠。一段 80% 是「开户送股票、入金返现」
的描述不是描述，抠掉广告只剩残渣。

```python
from musiclib import scrub
r = scrub.scrub(tags)
r.changed        # 是否改过
r.findings       # 每条：字段 / 命中 / 原因 / 改前 / 改后
```

`Converter(scrub_tags=True)` 是默认行为，改动在**写文件之前**汇总到
`converter.findings`，可以先审后跑。

## 封面补全（`CoverFetcher`）

源文件没有封面的专辑，可用 [sacad](https://github.com/desbma/sacad) 按
「艺人 + 专辑」下载。sacad 以**子进程**方式调用：它是 GPL-3.0，本包是 MIT，
用 exec 边界把许可隔开。

**已知限制**：

| 专辑 | 结果 |
|---|---|
| Latin 专辑名 | ✓ |
| Latin 专辑名（含空格） | ✓ |
| 中文专辑名 | ✗ |
| 中文专辑名（短） | ✗ |
| 中文艺人 + 拉丁专辑 | ✗ |

**中文专辑名 sacad 搜不到**（它的源站按拉丁文索引）。失败会被记进
`fetcher.misses`，该专辑就按「本来也没有封面」继续转换——不会报错，也不会卡住。

## 结构

```
musiclib/
  capabilities.py  能力矩阵 + 不支持项在动手前抛错
  itunesdb.py      iTunesDB 解析 + AIFF 尾部 ID3 封面提取（无 libgpod）
  convert.py       转 AAC / 打标 / 嵌封面
  musicapp.py      AppleScript 层：导入、回读、写歌词
  lyrics.py        LRCLib 取词，按时长窗口匹配
docs/
  LYRICS.md        歌词能到什么程度，以及为什么
  PRIOR-ART.md     前人做过什么，为什么没有一个能直接用
tests/
```

## 前人工具

`libgpod` / `iOpenPod` 解决「往 iPod 写」；`sacad` / `get_cover_art` 解决「给文件嵌封面」；`apple-music-local-lyrics` 用同样的 `track.lyrics` 机制。没有工具覆盖「本地曲库 → Music.app 库」这条完整链路。详见 `docs/PRIOR-ART.md`。
